EXPLORATORY DATA ANALYSIS (EDA) PROJECT
========================================

Project Title: Exploratory Data Analysis on Diwali Sales Dataset.

Author: Devansh Kumar
Description:
------------
This project performs Exploratory Data Analysis (EDA) on the given dataset to identify 
patterns, trends, correlations, missing values, outliers, and meaningful insights. 
The goal of EDA is to understand the structure of the data and prepare it for 
further modeling or decision-making.

----------------------------------------
1. OBJECTIVES OF THE PROJECT
----------------------------------------
• Understand the dataset structure  
• Identify missing values and data quality issues  
• Detect outliers  
• Generate summary statistics  
• Analyze distributions of numerical variables  
• Study categorical variables  
• Examine correlations between features  
• Visualize data for better understanding  
• Extract actionable insights  

----------------------------------------
2. DATASET DETAILS
----------------------------------------
• Dataset Name: Diwali Sales Dataset  
• Source:Kaggle 
• Number of Rows: 11251 
• Number of Columns: 15

----------------------------------------
3. TOOLS & LIBRARIES USED
----------------------------------------
• Python  
• pandas  
• numpy  
• matplotlib  
• seaborn  
• jupyter notebook  

----------------------------------------
4. STEPS PERFORMED IN EDA
----------------------------------------

A. Data Loading  
----------------
• Loaded dataset using pandas  
• Checked basic structure using .info() and .head()  

B. Data Cleaning  
----------------
• Handled missing values  
• Treated or removed outliers  
• Converted incorrect datatypes  
• Removed duplicate records  

C. Exploratory Analysis  
-----------------------
• Generated summary statistics  
• Plotted distributions of numerical variables  
• Analyzed categorical variables using countplots  
• Detected correlations using heatmaps  
• Used boxplots to identify outliers  
• Used pairplots to see feature relationships  

D. Insights & Observations  
--------------------------
• Found relationships between key variables  
• Identified skewed distributions  
• Highlighted categories with most influence  
• Found anomalies or unusual patterns
